Healthcare Performance & Patient Analytics Dashboard

📊 Project Overview

The Healthcare Performance & Patient Analytics Dashboard is an interactive Power BI dashboard developed to analyze healthcare performance, patient activity, hospital operations, financial performance, and patient experience.

The dashboard transforms healthcare data into an interactive reporting solution that enables users to monitor key performance indicators, identify trends, compare performance across locations and departments, and explore patient-level information.

The project demonstrates how data analytics and visualization can be applied to support data-driven healthcare decision-making.

---

🎯 Project Objectives

The dashboard was developed to answer important healthcare performance and management questions, including:

- How is patient activity changing over time?
- How do healthcare facilities perform across different states and branches?
- Which departments handle the highest patient activity?
- What are the revenue, cost, and profit patterns?
- How long do patients wait for services?
- How satisfied are patients with the services provided?
- What are the observed patient outcomes?
- What diagnoses and care patterns are present?
- How can patient-level information be explored for deeper analysis?

📌 Key Performance Indicators (KPIs)

The dashboard includes key healthcare performance measures such as:

- Total Patients
- Total Visits
- Total Revenue
- Total Cost
- Total Profit
- Average Revenue per Patient
- Average Waiting Time
- Average Satisfaction Score

These KPIs provide a quick view of healthcare performance while allowing users to explore the underlying patterns through interactive visuals.
