Health care Performance & Patient Analytics Dashboard

📊 Project Overview

The health care Performance & Patient Analytics Dashboard is an interactive Power BI dashboard designed to analyze healthcare performance and patient-related data across different states, branches, departments, and time periods.

The dashboard transforms healthcare data into meaningful insights that can support performance monitoring, operational decision-making, and improved patient experience.

🎯 Project Objectives

The main objectives of this project were to:

- Monitor overall healthcare performance
- Analyze patient visits and trends over time
- Evaluate revenue, costs, and profit
- Compare healthcare performance across states and branches
- Analyze patient distribution across departments
- Examine patient outcomes
- Monitor waiting time and patient satisfaction
- Identify patterns in diagnoses and patient-related data
- Provide detailed patient-level information for further analysis

🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

📌 Key Performance Indicators (KPIs)

The dashboard tracks key healthcare performance indicators including:

- Total Patients
- Total Visits
- Total Revenue
- Total Cost
- Total Profit
- Average Revenue per Patient
- Average Waiting Time
- Average Satisfaction Score

📈 Dashboard Analysis

1. Healthcare Performance Overview

The overview page provides a high-level summary of healthcare performance using KPI cards and interactive visualizations.

Key areas analyzed include:

- Patient visits over time
- Revenue and profitability
- Healthcare performance by state
- Patient distribution by department
- Revenue compared with target
- Patient outcome distribution

2. Patient Analysis

The patient analysis section provides a more detailed view of patient activity and outcomes.

It examines:

- Patient demographics and details
- Diagnoses
- Department utilization
- Patient outcomes
- Satisfaction
- Waiting time
- Patient-level performance

The dashboard also includes patient-level analysis that allows a selected Patient ID to display relevant patient information and details.

3. Management & Operational Analysis

The dashboard supports management-focused analysis by examining:

- Revenue and cost performance
- Profitability
- Branch performance
- State-level performance
- Department activity
- Patient experience indicators
- Operational trends

🔎 Interactive Features

The dashboard includes interactive filters and navigation features that allow users to explore the data from different perspectives.

Users can filter the analysis by:

- Date
- State
- Branch

The dashboard also includes navigation and detailed patient analysis to make it easier to move between different sections of the report.

💡 Key Insights

The dashboard was designed not only to present charts, but also to help identify meaningful patterns and areas that may require management attention.

Examples of areas explored include:

- Changes in patient visits over time
- Differences in healthcare performance across locations
- Department-level patient activity
- Revenue and cost patterns
- Patient outcomes
- Waiting time and satisfaction
- Diagnosis patterns, including common conditions such as malaria
